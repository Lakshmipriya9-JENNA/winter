About the Project

This is a simple Weather Forecast Application that I developed using the C programming language. The main idea behind this project is to display basic weather information for different cities through a simple menu-driven program.

Users can select a city and view its temperature, humidity, and general weather condition.

I created this project to improve my C programming skills and get more practical experience with concepts like conditional statements, switch cases, variables, and user input.

Features
Select from four different cities.
View the temperature of the selected city.
Check the humidity level.
Get a basic weather description such as Hot, Cold, or Pleasant.
Simple and easy-to-use menu.
Technologies Used
C Programming Language
GCC Compiler
Cities Available
Hyderabad
Mumbai
Delhi
Chennai
How to Run the Project

Step 1: Download or clone this repository.

Step 2: Open the project folder in your terminal.

Step 3: Compile the C program:

bash
gcc weather.c -o weather


Step 4: Run the program:

bash
./weather


On Windows, use:

bash
weather.exe
